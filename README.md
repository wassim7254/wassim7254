## `07` — PRINCIPLES

**Build for reality.**

Not just the happy path.

**Keep the source of truth clear.**

The database should enforce what the database can enforce.

**Make failures explicit.**

A failed operation should fail predictably.

**Prefer boring reliability over clever complexity.**

Use the simplest architecture that can correctly solve the problem.

**Design for the next developer.**

Code should remain understandable after the original author leaves.
